1- ما هي HTML؟

HTML هي لغة ترميز النص التشعبي، وتستخدم لإنشاء هيكل صفحات الويب. وهي الأساس الذي تبدأ منه رحلة تطوير المواقع الإلكترونية.

HTML = HyperText Markup Language

2- الهيكل الأساسي للصفحة

كل صفحة HTML تحتوي على عناصر أساسية تساعد المتصفح على فهم الصفحة. 

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

</body>

</html>

هذا هو الهيكل الأساسي لأي صفحة HTML.

3- العناوين (Headings)

تستخدم العناوين لتنظيم محتوى الصفحة، ويوجد ستة مستويات تبدأ من h1 إلى h6. 

<h1>Main Heading</h1>

<h2>Second Heading</h2>

<h3>Third Heading</h3>

النتيجة:

عنوان رئيسي

عنوان فرعي

عنوان أصغر

4- كتابة الفقرات (Paragraphs)

يستخدم الوسم p لكتابة النصوص والفقرات داخل صفحة الويب. 

<p>
    Welcome to my website!
</p>

النتيجة:

Welcome to my website!

5- إنشاء الروابط (Links)

يستخدم الوسم a لإنشاء روابط تنقل المستخدم إلى صفحات أو مواقع أخرى. 

<a href="https://www.google.com">
    Visit Google
</a>

النتيجة:

زيارة Google

6- إضافة الصور (Images)

يستخدم الوسم img لإضافة الصور إلى صفحات الويب. 

<img src="photo.jpg"
     alt="My Image"
     width="200">

src يحدد مكان الصورة، وalt يصفها، وwidth يحدد عرضها.

7- إنشاء القوائم (Lists)

يمكن استخدام ul لإنشاء قائمة غير مرتبة، وli لإضافة عناصر إليها. 

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

النتيجة:

  • HTML
  • CSS
  • JavaScript

8- أهم وسوم HTML

  • html : العنصر الرئيسي للصفحة.
  • head : معلومات الصفحة.
  • title : عنوان الصفحة في المتصفح.
  • body : محتوى الصفحة.
  • h1 : عنوان رئيسي.
  • p : فقرة نصية.
  • a : رابط.
  • img : صورة.
  • br : سطر جديد.
  • ul : قائمة غير مرتبة.
